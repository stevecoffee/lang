# L3 — detailed design

Parent: L0, L1, L2  
Ready enough for an implementer to emit code (L4) under closed-context compile.

## Todo item (in memory)

- id — stable for the life of the item  
- title — text  
- done — yes/no  

Order of the list = display order (reorder changes this order).

## List state

- items — ordered list of todos  
- selected — index of the highlighted row (or “none” only if list empty)  
- mode — normal | editing  
- edit_buffer — text while mode is editing (not committed until leave-edit-save)

### Rules

- Navigate only in normal mode; up/down move selected within the list  
- Reorder only in normal mode; shift+up/down swaps selected with neighbor; selection follows the item  
- Enter in normal mode on a row → editing, edit_buffer = that title, cursor in the field  
- Enter in editing → commit: title = trimmed edit_buffer; if empty, keep previous title; back to normal  
- Escape (or equivalent cancel key) in editing → discard buffer; back to normal  
- Space in normal mode → flip done on selected  
- Add → insert new item (empty or “New todo”), select it, preferably enter editing  
- Delete → remove selected; select a sensible neighbor; if list empty, selected = none  
- Every successful change to items/order/titles/done → Store save  

## Store

- On startup: load items or start empty  
- On save: write full list (order, id, title, done)  
- After restart: same order and fields  

## Screen

- Full screen list: each row shows checkbox + title  
- Selected row clearly marked  
- In editing, selected row shows edit_buffer and an obvious “editing” cue  
- Done rows still visible; checkbox reflects done  

## Input map (from L1, fixed here)

| Key | Mode | Effect |
|-----|------|--------|
| up / down | normal | move selection |
| shift+up / shift+down | normal | reorder selected |
| enter | normal | start edit |
| enter | editing | commit edit |
| escape | editing | cancel edit |
| space | normal | toggle done |
| (add key) | normal | add item — pick one obvious key at compile (e.g. `a` or `n`) and document in report |
| (delete key) | normal | delete selected — pick one (e.g. `d` or delete) and document in report |
| (quit) | normal | quit app — pick one (e.g. `q`) and document in report |

## Checks (for tests at L4)

- Navigate and reorder change selection/order as above  
- Edit commit / cancel / empty title rules hold  
- Toggle done flips and stays after restart  
- Add and delete work; empty list OK  
- Restart restores order, titles, done
