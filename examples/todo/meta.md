# Todo editor

Full-screen app for a **personal todo list**. One main view. Stays on the machine (no cloud).

## Not this

Accounts, sync, labels/projects, plugins, notes, multi-page chrome.

## Shape

- One full-screen list; add and edit **in place** (you never leave this view for basic work)
- A todo is: **id**, **title**, **done**
- Save locally; still there after restart

## Does

- Add a todo  
- Rename (empty title does not stick)  
- Toggle done (done items stay on the list, look different)  
- Delete (ask once before delete)  
- Empty list: obvious way to add the first item  

## Check

The **Does** list works, including **after restart**.
