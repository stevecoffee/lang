## Assumptions (for a usable list; not stated in L0)

- There is a selected row whenever the list is non-empty  
- Navigate up/down changes which row is selected  
- Reorder moves the selected item and keeps it selected  
- Edit mode edits the selected item’s title  
- Checkbox = done / not done on the selected item  
- Done items stay on the list (still visible)  
- Add exists: create a new item and select it (key not fixed in L0)  
- Delete exists: remove selected item (key not fixed in L0)  
- Leave edit with save: new title kept (empty title → keep old title)  
- Leave edit with cancel: title unchanged (key not fixed in L0)  
- List (order, titles, done) survives restart
