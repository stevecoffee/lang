# L1 — behavior

Parent: L0

## List

- Shows todo items (each has a title and a done checkbox)
- One item is selected at a time
- Empty list is allowed; you can still add the first item

## Key bindings

- arrows — move selection up/down  
- shift+arrow up/down — reorder: move selected item up/down in the list  
- enter — toggle edit mode on the selected item’s title  
- space — toggle the selected item’s checkbox (done / not done)

## Other actions (needed for a usable list)

- Add a new item (how is up to design below; must be easy from the keyboard)  
- Delete the selected item  
- Leave edit mode and keep the new title  
- Leave edit mode and cancel (title unchanged)  
- Empty title does not stick on save of edit  

## Lasts

- List order, titles, and done state still there after you quit and open again  

## Check

Bindings and actions above work, including after restart.
